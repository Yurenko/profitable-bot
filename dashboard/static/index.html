Що означають метрики

          
Max DD — максимальна просадка: наскільки сильно equity падало від свого піку (у %). Менше = стабільніше.

          
Sharpe — прибуток відносно ризику/волатильності. >1 добре, >2 дуже добре. На короткому синтетичному тесті може бути завищений.

        

        

        

          
Закриті угоди бектесту (як рахується Win Rate)

          
Win Rate = кількість продажів з PnL > 0 / усі закриття. Buy не рахуються.
